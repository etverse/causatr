# Python oracle fixtures

M-estimation sandwich references computed with Python's `delicatessen` package
(Zivich & Breskin 2021) for cross-language validation of `causatr`'s analytic
IF variance engine.

## Requirements

```
python >= 3.9
numpy  >= 1.24
pandas >= 2.0
scipy  >= 1.10
```

Install:

```bash
pip install numpy pandas scipy
```

`delicatessen` is **not** used in these scripts — the sandwich is computed
directly from the estimating-equation Jacobian (scipy linear solve) to avoid
an additional dependency. The math is identical to `delicatessen.MEstimator`.

## Files

| Script | Fixture | Description |
|---|---|---|
| `glmtp_sandwich_tau2.py` | `glmtp_sandwich_tau2_results.csv` | G-LMTP grace_period(1), tau=2, binary, n=500, seed=2025 |

## Regenerating

Run from the repository root:

```bash
python tests/testthat/fixtures/python/glmtp_sandwich_tau2.py
```

The script reads `glmtp_tau2_data.csv` (generated by
`glmtp_delay_data(n=500, seed=2025, tau=2)`) and writes
`glmtp_sandwich_tau2_results.csv`.

Regenerate the data CSV from R:

```r
devtools::load_all()
source("tests/testthat/helper-glmtp-dgp.R")
d <- glmtp_delay_data(n=500L, seed=2025L, tau=2L)$data
write.csv(d, "tests/testthat/fixtures/python/glmtp_tau2_data.csv", row.names=FALSE)
```
